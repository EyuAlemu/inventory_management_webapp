# Admin User Guide

This guide explains how to use the app as an `admin` user. Admins work with locations and products assigned by Ruth. Admins can manage location stock and pricing, create invoices, record payments, review returns, manage transfers, and view scoped activity.

## Before You Start

Ruth must assign:

1. At least one location.
2. At least one inventory product.

If the app says a location or product is missing, ask Ruth to update **Locations** or **Users & Access**.

## Dashboard

Use **Overview** to review your assigned stock, sales, and activity.

1. Log in with your admin account.
2. Click **Overview**.
3. Review assigned-location stock.
4. Review supplied-product activity.
5. Review low stock and recent transactions.

## Stock & Pricing

Use **Stock & Pricing** to manage stock and prices for assigned locations.

1. Click **Stock & Pricing**.
2. Select a location.
3. Select an inventory item.
4. Enter location quantity.
5. Enter location price.
6. Click **Save Stock / Price**.
7. Review all visible location stock in the table.

## Financials

Use **Financials** to create invoices and record payments for assigned locations and assigned products.

### Create an Invoice

1. Click **Financials**.
2. Select location.
3. Select item.
4. Enter customer name.
5. Enter quantity.
6. Confirm unit price.
7. Review invoice preview.
8. Click **Create Invoice**.

The app reduces location inventory and creates an invoice.

### Record Payment

1. Click **Financials**.
2. Select an invoice.
3. Enter payment amount.
4. Select payment method.
5. Enter reference number if needed.
6. Click **Record Payment**.

The app prevents overpayments.

### Review Financials

1. Click **Financials**.
2. Review invoice total, paid amount, and outstanding amount.
3. Filter invoices by status.
4. Review payment summary by method.
5. Review payment history.

## Returns / Damaged

Use **Returns / Damaged** to review or record returns related to assigned records.

1. Click **Returns / Damaged**.
2. Select location.
3. Select item.
4. Enter quantity.
5. Select condition.
6. Enter reason.
7. Click **Save Return**.
8. Review return records.

## Transfers

Use **Transfers** to record movement between assigned locations.

1. Click **Transfers**.
2. Select item.
3. Select source location.
4. Select destination location.
5. Enter quantity.
6. Select status:
   - `pending`: record transfer request only.
   - `completed`: update source and destination stock immediately.
7. Click **Save Transfer**.
8. Review transfer records.

## Activity Logs

Use **Activity Logs** to review activity related to assigned locations and products.

1. Click **Activity Logs**.
2. Search by user or item code.
3. Review source, quantity before, quantity changed, and quantity after.
4. Confirm verification when available.

## Detailed Walkthrough: Create Invoice and Record Payment

### Step 1: Confirm Stock

1. Click **Stock & Pricing**.
2. Select your assigned location.
3. Select the item.
4. Confirm quantity and price.
5. Click **Save Stock / Price** if changes are needed.

### Step 2: Create Invoice

1. Click **Financials**.
2. Select location.
3. Select item.
4. Enter customer name.
5. Enter quantity.
6. Confirm price.
7. Click **Create Invoice**.

### Step 3: Record Payment

1. Stay on **Financials**.
2. Select the invoice in **Record Payment**.
3. Enter payment amount.
4. Select method.
5. Enter reference number if needed.
6. Click **Record Payment**.

### Step 4: Verify Activity

1. Click **Activity Logs**.
2. Search for the item code.
3. Confirm the transaction appears.
4. Confirm verification is `Verified`.
